# Canva prompts for the eleven homepage banners

These replace the drawn banners in `public/banners/`. Generate in **Canva →
Magic Media → Image**, set the aspect ratio to **landscape 16:9**, then run the
importer at the bottom of this file.

---

## Read this before generating

**Four constraints are not stylistic. Break them and the banner breaks.**

1. **The subject must sit on the RIGHT.** The carousel lays its headline over
   the left of the frame. Anything interesting on the left is covered by type.
   Every prompt below ends with a composition instruction that says so — keep
   it.

2. **No text in the image.** The headline, the body line and the button are
   drawn by the site in real type, in three languages. Text baked into the
   picture would sit underneath them, in English only, and image generators
   render lettering badly in any case. Every prompt ends with a negative
   instruction for this.

3. **One strong colour per banner.** The site's two navigation bars take their
   colour from whichever banner is on screen — that is a feature you asked for,
   and it only works if each banner has a hue worth borrowing. The colour
   direction in each prompt is chosen so no two banners sit on the same hue.
   A washed-out grey photograph leaves the bars on the default navy.

4. **No government emblems or real documents.** No State Emblem, no Ashoka
   lion capital, no ministry or department logo, no recognisable PAN card,
   passport or GST certificate. Reproducing them is a trademark problem and a
   forgery risk. Props should read as "official paperwork" generically.

**On people.** You asked for humans, and AI-generated people are the right way
to get them: a photograph of a real person used in advertising needs a model
release, which stock libraries often cannot evidence. A generated person is
nobody, so there is no publicity right to infringe. Check faces and hands
before you ship — generators still get them wrong — and regenerate rather than
retouch.

**Canva's terms.** Content from Magic Media is usable commercially under
Canva's licence, but that licence is Canva's to change. Read it once for
yourself; do not take this file's word for it.

Every prompt below already includes this. If you write your own, append it:

> Subject positioned in the right third of the frame. The left 45% is quiet,
> uncluttered negative space with nothing important in it. Natural light,
> shallow depth of field, professional editorial photography, 16:9 landscape.
> No text, no letters, no numbers, no logos, no signage, no watermarks, no
> brand names.

## Getting them onto the site

Download from Canva at the largest size offered — the importer scales down, and
scaling up is what makes a banner look soft.

Then, for each one:

```bash
node scripts/import-banner.mjs 1 ~/Downloads/udyam-from-canva.png
```

The first argument is the position number from the headings above. The importer
crops to 16:9, resizes to 1600×900 and writes WebP, because image optimisation
is switched off on this project and nothing downstream will compress it. See
the note in `next.config.ts`.

When all eleven are in:

```bash
node scripts/extract-banner-colours.mjs
node --env-file=.env.local scripts/apply-banners.mjs
```

The first re-reads the hue of each new picture so the navigation bars follow
them. The second points the `promotions` table at the new files — **do not skip
it.** The home page reads its banners from that table, not from the code, and
changing only the files leaves production showing the old ones.

Then commit, push, and promote the deployment.
